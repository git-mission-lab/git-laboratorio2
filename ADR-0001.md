#### ADR###
# ADR-0001 - Adopción de Git para el control de versiones

## Estado

Propuesto

## Fecha

27/07/2026

## Contexto

La Arquitectura Empresarial necesita una forma de controlar los cambios realizados sobre documentos técnicos como ADR, diagramas, estándares y demás activos de arquitectura.

Actualmente estos documentos se administran mediante múltiples versiones distribuidas entre diferentes personas, lo que dificulta conocer cuál es la versión más reciente.

## Decisión

Adoptar Git como sistema de control de versiones para los activos técnicos de Arquitectura Empresarial.

## Consecuencias

### Positivas

- Historial completo de cambios.
- Trazabilidad de las modificaciones.
- Colaboración entre arquitectos.
- Recuperación de versiones anteriores.

### Riesgos

- Curva de aprendizaje inicial.
- Necesidad de definir buenas prácticas de colaboración.
